# Проверка гипотез в бизнесе (GoFast)

## Описание проекта
В этом проекте я выступила в роли аналитика крупного сервиса проката самокатов GoFast. Компания предоставила три датасета с данными о пользователях сервиса, их поездках за один год, а также стоимости услуг в подписках.

**Цель исследования:** проанализировать демографию пользователей и особенности использования самокатов, а также определить возможную выгоду от распространения платной подписки на самокаты.

**Основные пункты исследования:**
1. Загрузка и предварительная подготовка данных.
2. Исследовательский анализ данных (EDA): изучение географии и демографии пользователей, анализ длительности и дистанции поездок.
3. Объединение данных о пользователях, поездках и подписках.
4. Подсчёт выручки и поиск пользователя с максимальной выручкой.
5. Проверка статистических гипотез с помощью t-теста.
6. Моделирование распределения длительности поездок (CDF и PPF).

**Использованные библиотеки:**
- `pandas`
- `matplotlib.pyplot`
- `scipy.stats`

## Выводы
1. Доля несовершеннолетних пользователей составляет около 5%.
2. Средняя длительность поездки — около 18 минут. Пользователи с подпиской (ultra) ездят дольше (19 минут), чем без подписки (17 минут).
3. Средняя дистанция поездки у подписчиков не превышает 3130 метров.
4. Пользователи с подпиской приносят больше выручки (в среднем 359 руб. в месяц) по сравнению с пользователями без подписки (322 руб. в месяц).
5. Вероятность поездки более 30 минут — около 2%. Вероятность поездки от 20 до 30 минут — около 37.7%.
